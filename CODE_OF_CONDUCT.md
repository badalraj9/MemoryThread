# Code of Conduct 🤝

## TL;DR

Be kind. Be respectful. Help each other learn.

## The Longer Version

We want Memory Thread to be a welcoming place for everyone — whether you're a seasoned systems engineer or just starting to explore AI memory systems.

### What We Expect

- **Be patient** — Not everyone has the same background. Explain things kindly.
- **Be respectful** — Disagree with ideas, not people.
- **Be constructive** — Criticism is welcome when it comes with suggestions.
- **Be inclusive** — We don't care about your background, only your ideas.

### What's Not Okay

- Harassment of any kind
- Personal attacks or insults
- Trolling or inflammatory comments
- Sharing others' private information

### When Things Go Wrong

If someone makes you uncomfortable or violates this code of conduct:

1. **Reach out** — Contact the maintainers privately
2. **We'll listen** — Every report is taken seriously
3. **We'll act** — Appropriately and fairly

### For Maintainers

We hold ourselves to the same standard. If we mess up, call us out.

## The Goal

We're building something that could genuinely help AI systems be more honest and reliable. That's exciting! Let's keep the focus on the work and treat each other well along the way.
